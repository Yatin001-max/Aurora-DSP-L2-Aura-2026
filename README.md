## ❓ FAQ

**Q: Is there any risk of audio glitches or crashes during live use?**  
A: Aurora DSP L2 Aura 2026 is built for stability, but audio dropouts can occur with very high buffer sizes or incompatible drivers. We recommend using an ASIO driver on Windows for best performance. No software is immune to system-level issues, but the risk is minimized with reasonable hardware.

**Q: The installer fails with an error about missing DLLs / frameworks. What should I do?**  
A: Ensure you have the latest Microsoft Visual C++ Redistributable (2015-2022) installed for Windows, and that your macOS is updated to at least version 12. If the problem persists, run the installer as Administrator and verify your antivirus is not blocking the executable.

**Q: Can I use this with my DAW (e.g., Ableton, FL Studio, Logic)?**  
A: Yes, Aurora DSP L2 Aura 2026 can be used as a standalone application or routed into any DAW via virtual audio cables (e.g., VB-Cable on Windows, BlackHole on macOS). It does not function as a VST/AU plugin, but it processes any incoming audio signal.
